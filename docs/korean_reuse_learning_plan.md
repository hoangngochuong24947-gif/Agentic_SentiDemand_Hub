# 开源复用与学习方案

## 四个参考项目的复用结论

### PyKoSpacing

- 适合复用的能力：韩语空格恢复、SNS 风格评论预处理。
- 适合的接入方式：做成可选预处理步骤，不作为硬依赖。
- 注意事项：GPL 协议，若直接复用代码需严格标注来源并评估分发策略。

### KoNLPy

- 适合复用的能力：`Okt` / `Mecab` 形态分析、词性标注、名词抽取。
- 适合的接入方式：作为韩语分词可选后端。
- 注意事项：Java/JVM 依赖明显，部署说明必须写清楚。

### ECommerceCrawlers

- 适合复用的能力：登录态维护、Cookie 池、代理监听、异常重试思路。
- 适合的接入方式：只复用设计模式，不直接照搬老旧脚本。
- 注意事项：包含明显绕过检测与站点定制逻辑，只能做学习参考，不能默认用于生产。

### Crawlee

- 适合复用的能力：现代化爬虫骨架、请求队列、重试、会话管理、浏览器自动化。
- 适合的接入方式：未来若要扩展韩国电商爬虫，优先基于 Crawlee 或其 Python 版重构。
- 注意事项：当前仓库是 Python 项目，建议把爬虫层独立成子项目或服务。

## 学习路径

1. 先学 `KoNLPy` 的 `Okt` 分词输出格式，搞清韩语 token 粒度。
2. 再学 `PyKoSpacing` 的“分词前空格恢复”价值，决定是否引入为可选步骤。
3. 然后对照 `ECommerceCrawlers` 与 `Crawlee`，把“临时脚本式爬虫”升级成“可维护爬虫框架”。
4. 最后把学到的模式沉淀到 `docs/Skills.md` 和 hooks 日志里。
